# philosophy-for-agents

Instruction files distilled from my dictated thinking on language, meaning, metaphor and writing.

[All skills](../README.md)

- [expository-writing](expository-writing/): Keeps an agent's prose literal and specific: every sentence says something checkable.
- [judgement-vs-code](judgement-vs-code/): Helps an agent decide when a task needs reading and judgement rather than string matching.
- [metaphor](metaphor/): Helps an agent use and examine metaphors without over-extending them.
- [text-as-graph](text-as-graph/): Treats documents and courses as connected parts so they can be reused and recombined without copies drifting.
- [writing-modes](writing-modes/): Makes an agent decide who a text is for and in whose name it speaks before it writes, and load only that register's rules.
