What is a skill?

What a skill is

A skill is a folder with instructions for agents on how to perform certain tasks consistently.

What is in the folder

The folder contains a SKILL.md file that describes what the skill does and links to other instructions in a references/ folder or to scripts the agent can run in a scripts/ folder. Some skills have only a single file; others are extensive collections of instructions and scripts, and some also contain assets/ such as images. Some skills depend on other apps being installed on your machine.

Which agents and models

Agent skills are a universal standard and work with any desktop agent, and now with some chatbots. Some skills have instructions that assume the capabilities of a certain model or agent. They will still work with any model, but the model may be less reliable on those tasks. For example, the image-to-design skill assumes the agent can generate images; at the time of writing, Codex and the ChatGPT desktop app can do this.

Review your skills over time

As the models behind agents get better, the need for some skills decreases because the models can already make good decisions. A skill can even become counterproductive when it goes against the agent's ability to make good decisions. Review your skills periodically to make sure they still serve their intended purpose.

How to install a skill

Installing a skill

To install a skill means registering it with your agent, so it can use the skill when needed, and putting it in a folder on your computer that the agent can access. You can install a skill as it is, ask the agent to modify it for your purposes, or have it build a new skill to fit your workflow. There are three ways to install one.

Three ways to install a skill

  1. 1 Ask your agent to choose

    Open Claude Code, Codex or another agent and paste this prompt. Replace the … with a sentence about your work. The agent reads the repository, suggests skills and installs the ones you agree to.

    Look at https://github.com/techczech/dominiks-agent-skills and tell me which of these skills would fit my work. I mainly … Install the ones I pick.

  2. 2 Install with the skills command

    Run this in a terminal. It lists the skills in the repository and lets you choose which ones to install. You need Node.js.

    npx skills add techczech/dominiks-agent-skills

  3. 3 Copy the skill’s folder

    Download the repository and copy one skill’s folder into your agent’s skills folder. For Claude Code that is ~/.claude/skills/<name>. Skills marked ‘own repository’ are copied from their own repository in the same way.

    git clone https://github.com/techczech/dominiks-agent-skills
cp -r dominiks-agent-skills/<category>/<name> ~/.claude/skills/<name>

Check before you install

Always ask your agent to review a skill before you use it, to make sure it has no hidden instructions and no scripts that have bugs or are malicious.

Philosophy for agents

On 17 July 2026 I started dictating conversations about how I think about language and meaning. I have a background in cognitive linguistics and metaphor research, and I wanted agents to work from the ideas I use myself rather than from their defaults. Each topic became an instruction file that agents load, with an essay version for people.

A model drafted each distillation, a model from a different family reviewed it independently, and I decided every disputed point. The essays were drafted alongside and are not yet published.

Grep and Grok

judgement-vs-code

Says when a task over language needs reading and judgement (Grok) and when string operations (Grep) are right; the failure is using one where the other belongs. The core line from the series is "we think in schemas and we speak in propositions", and the name comes from my Grep and Grok cartoons.

Text as a graph

text-as-graph

Treats documents and courses as graphs of connected parts. Slides, handouts and outlines are views derived from them, and every copy records where it came from and how to regenerate it. This was the first file in the series and set the pattern for the rest.

Metaphor

metaphor

Metaphor mappings are partial and negotiated, so an agent should neither dismiss a metaphor nor import everything from its source. It draws on my metaphor research (Metaphor Hacker blog).

Expository writing

expository-writing

Every sentence should say something a reader can use or dispute, with no decorative or journalistic language unless asked. On 24 July 2026 a live correction added that register (how sentences are written) and structure (layout) are separate axes, and a complaint about one is not licence to change the other.

Skill source for Expository writingShow in list

Writing modes

writing-modes

Before writing any prose, the agent decides who the text is for and in whose name it speaks: for agents (instruction files, logs), for you (chat, READMEs, explanations), or as you (anything sent or published under your name, using only your own sources and voice). It announces the register and reads only that register's rules. It came out of the same series as Expository writing: I renamed the registers on 24 July 2026 after correcting an agent that had announced a register without applying it. You can rename the registers, add one, or point the 'as you' register at your own voice notes.
