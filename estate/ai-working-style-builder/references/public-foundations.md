# Public Foundations

Offer these as optional resources. The working-style process must not depend on installation or assume that one pattern suits everyone.

## Readability

- Guide: <https://readability.edutools.fyi>
- Public skill: <https://github.com/techczech/readability-skill>

Use space, chunks, guides, information structure, and simple language as hypotheses to demonstrate. Test preferences on tasks; do not rely on intuition or diagnosis alone.

## HTML Reading, Review, and Sharing

- Public skill: <https://github.com/techczech/dominiks-agent-skills/tree/main/dev/single-html-document>
- Rationale and examples: <https://claude.com/blog/using-claude-code-the-unreasonable-effectiveness-of-html>

Offer three separate experiences progressively:

1. a polished reading version;
2. an optional decision and feedback version that exports annotations back to an agent or chatbot;
3. a separately prepared sharing version.

Keep Markdown as the editable source. Accommodate Word and PDF preferences while explaining the navigation, accessibility, annotation, and reuse benefits of HTML.

## Durable Agent Instructions

- Global instructions: <https://github.com/techczech/dominiks-agent-skills/tree/main/estate/global-agent-instructions>
- Instruction streamlining: <https://github.com/techczech/dominiks-agent-skills/tree/main/estate/agents-md-streamline>

Use one short current instruction set with links to detail loaded when relevant. Keep the chronological journal and lessons outside the always-loaded instructions.

## Sharing Boundary

- Link public resources directly.
- Do not expose private repositories, paths, raw dictation, identities, organisations, clients, or machine details.
- Generate a separate privacy-checked sharing copy; do not rely only on hidden filters inside a private document.
- Verify changing product names and capabilities before recommending a specific chatbot or desktop agent publicly.
