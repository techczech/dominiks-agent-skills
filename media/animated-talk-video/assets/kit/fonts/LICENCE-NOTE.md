# Font licences

Latin subsets of four families, copied from TalkWeaver (`src/renderer/src/assets/fonts/` and the round-9 design `fonts/`), which got them from google-webfonts-helper (the files Google Fonts serves). All are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org/open-font-license-official-text/): bundling and redistribution with software are allowed, not sale of the fonts by themselves; keep the copyright and licence notices.

- Fraunces: Copyright 2020 The Fraunces Project Authors (https://github.com/undercasetype/Fraunces). Weights 400, 600. Licence text: `FRAUNCES-LICENSE.txt`.
- Alegreya Sans: Copyright 2013 The Alegreya Sans Project Authors (https://github.com/huertatipografica/alegreya-sans). Weights 400, 500, 700. Licence text: `ALEGREYA-SANS-LICENSE.txt`.
- Geist: Copyright 2024 The Geist Project Authors (https://github.com/vercel/geist-font). Variable weight 100-900. Licence text: `GEIST-LICENSE.txt`.
- Inter: Copyright The Inter Project Authors (https://github.com/rsms/inter). Weights 400, 600, 700. Licence text: `INTER-LICENSE.txt`.

Which family is used is set by the look token `type` (see `templates/_fonts.mjs`).
