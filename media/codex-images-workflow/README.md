# codex-images-workflow

## Scope

Create and maintain reproducible generated-image artefacts with a brief-first workflow, stable naming, per-image Markdown briefs, and explicit versioning. Use when an agent is asked to generate posters, mockups, concept art, UI screens, boards, or other project image assets that should be stored in the project or your archive location rather than left in a tool cache. The workflow is independent of which image model or agent produces the image.

## Trigger

- Skill trigger: generated images that the project should be able to regenerate or revise later.
- Procedure: see `SKILL.md`.
